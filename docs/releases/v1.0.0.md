# MEC v1.0.0

The first stable release of MEC, a safe capability-aware terminal
control center for MSI laptops on Linux.

## Hardware safety first

- Safe capability-aware hardware detection: MEC discovers what the
  running machine exposes through the upstream Linux `msi-ec` kernel
  interface instead of trusting model allowlists.
- `READY` / `READ-ONLY` compatibility policy: machines the interface
  does not support stay usable for monitoring while every write path is
  prohibited, not attempted.
- Unknown or inconsistent hardware fails closed to read-only.
- No arbitrary EC register access anywhere in the tool.
- No automatic privilege helper: MEC runs with current-process
  permissions, and denied writes fail with a typed `AccessDenied`
  instead of escalating.
- Physical hardware write behavior has not been physically validated;
  write semantics are covered by fake sysfs integration tests.

## What is included

- Full CLI: status, monitoring, `doctor` diagnostics, and safe typed
  hardware controls behind an explicit write boundary.
- Monitoring views with temperature history and fan graphs.
- Interactive seven-screen TUI (Dashboard, Performance, Fans, Battery,
  Devices, Profiles, Diagnostics) with command palette, notifications,
  and help overlays.
- Safe typed controls: supported `READY` controls run only after an
  explicit confirmation.
- Profiles with rollback: preset and custom TOML profiles apply through
  validated transactions that roll back in reverse order on failure.
- Configuration and themes: `~/.config/mec/config.toml` with strict
  validation and atomic saves, plus named themes with runtime
  switching.
- Diagnostics and export: read-only `mec doctor` compatibility checks
  and a privacy-conscious `mec doctor --export` report for GitHub
  issues (no serials, hostnames, network data, or profile contents).

## Release packages

Supported architectures: `x86_64-unknown-linux-gnu` and
`aarch64-unknown-linux-gnu`, each built natively on its own runner.

- Portable archives: `mec-<target>.tar.gz` with `SHA256SUMS` covering
  every release file (checksums, not signatures).
- `.deb` packages for the Debian/Ubuntu family (`amd64`, `arm64`).
- `.rpm` packages for the RPM family (`x86_64`, `aarch64`).
- Reproducible AUR (`mec-bin`) `PKGBUILD` / `.SRCINFO` generation from
  the released checksums (published as release assets; not submitted
  to the AUR automatically).
- [Installation](../installation.md), [Upgrade](../upgrade.md), and
  [Uninstall](../uninstall.md) guides.
